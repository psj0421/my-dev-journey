## Git이란?
버전관리시스템이다. 우리가 사실 매번 수정 할때마다 따로 복사해서 저장하는 건 번거로우니 깃으로 변경기록을 편리 하게 관리한다 필요하면 예전 시점으로 되돌릴 수 있고 여러 사람이 코드를 공유해서 함께 관리할 수도 있다.

## 오늘 써 본 명령어
- git init : 해당 폴더를 세이브의 포함할 공간으로 만드는 것
- git status : 현재 상태
- git remote : 내 깃허브에 연결하는 것
- git add : 이번 세이브의 포함할 파일을 고르는 것
- git commit : 저장(내 컴퓨터의 기록)
- git push : 내 깃허브에 업로드
